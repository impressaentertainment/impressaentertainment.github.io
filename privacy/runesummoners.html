Rune Summoners プライバシーポリシー

Impressa Entertainment, Inc.　制定日: 2026年11月15日

Impressa Entertainment, Inc.（以下「運営」）は、ゲーム「Rune Summoners」（以下「本ゲーム」）で扱う情報を、次のとおり扱います。本ゲームに広告や外部の利用状況解析ツールは入っていません。

1. いただく情報と使いみち

情報いただくとき / 使いみち
プレイヤーID・プレイヤー名・アイコンにしたカード遊ぶとき、名前を決めたとき / オンライン対戦で相手に表示、プレゼントの受け取り、お問い合わせへの対応
セーブデータ（持っているカード・デッキ・アイテム・購入の履歴・年齢の区分など）、端末の種類データ連携を使うとき / ほかの端末への引き継ぎ、同じデータを2台で同時に使えないようにするため
Steam ID、端末ごとの識別子、通信のための情報（IPアドレスなど）オンライン対戦・ランク戦のとき / 対戦相手との接続、ランクの記録、不正の防止
対戦の結果とその証拠になる記録ランク戦のとき / 結果が正しいか確かめるため
作ったカードの絵・動画のコマ・文字、プレイヤー名カードを作ったとき、名前を決めたとき / 規約に反する内容を自動でチェックし、必要なときは運営が審査するため
購入の情報（注文番号・商品・金額）有料の商品を買うとき / 商品のお渡し、不正な購入の防止、お問い合わせへの対応。クレジットカードの番号などは各ストアが扱い、運営には届きません
通報・意見の内容、そのときの画面、直前の対戦の記録通報・意見を送ったとき / 違反への対応、ゲームの改善

2. 外部のサービス（情報を渡す先）

上の使いみちのため、次の会社のサービスを使います。一部は日本の外にあります。

Amazon Web Services（サーバー・保存・画像の自動チェック）セーブデータ、作ったカード、購入の確認、通報 ／ オーストラリア
OpenAI（文字の自動チェック）カードの文字、プレイヤー名 ／ アメリカ
Epic Games（Epic Online Services、オンライン対戦）端末の識別子または Steam ID、表示名、通信のための情報 ／ アメリカ
Valve（Steam）・Google（Google Play）・Apple（App Store）購入の情報 ／ アメリカ

これらの国には個人情報を守る法律がありますが、日本の法律と同じではありません。各国の制度は、個人情報保護委員会のページでご覧いただけます。

3. ほかへの提供

法令にもとづく場合のほかは、上の外に情報を渡しません。情報を売ったり、広告に使ったりもしません。

4. 保存する期間

  • セーブデータ: データ連携を使っているあいだ。サーバーには新しいもの2つだけを残します
  • 審査に出したカード・通報・意見: 対応が終わってから6か月
  • 購入の情報: 法令で決まった期間

5. 情報の開示・削除

自分の情報を見たい、直したい、消してほしいときは、プレイヤーIDを添えて下のメールにご連絡ください。消すと、そのデータはもう元に戻せません。

6. お子さまの情報

13歳未満の方は、保護者の同意をもらってから遊んでください。同意なく情報をいただいたと分かったときは、消します。

7. 安全のためにしていること

通信は暗号化（HTTPS）しています。データ連携は、連携コードとパスワードがないと読めません。管理画面に入れるのは運営だけです。

8. 変更

このポリシーを変えるときは、このページとゲーム内でお知らせします。

Rune Summoners Privacy Policy

Impressa Entertainment, Inc. — Effective: November 15, 2026

This policy explains how Impressa Entertainment, Inc. ("we") handles information in the game "Rune Summoners" (the "Game"). The Game contains no advertising and no third-party analytics tools. If this English version and the Japanese version differ, the Japanese version prevails.

3. Sharing

Except where required by law, we do not share your information beyond the providers above. We never sell it or use it for advertising.

4. Retention

  • Save data: while you use Data Link. The server keeps only the two latest versions
  • Cards sent for review, reports and feedback: 6 months after we finish handling them
  • Purchase information: for the period required by law

5. Access and deletion

To see, correct or delete your information, email us with your Player ID. Deleted data cannot be restored.

6. Children

Children under 13 need a parent's or guardian's consent to play. If we learn that we received information without that consent, we will delete it.

7. Security

All communication is encrypted (HTTPS). Data Link data can only be read with its link code and password. Only we can access the admin pages.
